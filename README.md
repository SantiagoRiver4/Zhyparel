## 🏆 Misión destacada

### 🏫 Campus Space Scheduler
Sistema web para gestionar reservas de laboratorios, auditorios y salas de cómputo.

- ✅ **Cero cruces de horario**: restricción `EXCLUDE` en PostgreSQL, a prueba de solicitudes simultáneas.
- 🔐 **Roles y permisos** con RLS: administrador y estudiante, con cambio de rol protegido en la base de datos.
- ⏱️ **Regla de negocio gestionada con SDD**: límite de 4 horas consecutivas, especificado con OpenSpec antes de codificarse.
- 🧪 Pruebas unitarias con Vitest, verificación SQL y matriz de trazabilidad requisito → código → prueba.

`TypeScript` · `React` · `TanStack` · `Supabase` · `PostgreSQL` · `Vitest` · `OpenSpec`
